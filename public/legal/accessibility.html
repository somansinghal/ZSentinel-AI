Accessibility Statement

Last Updated: September 27, 2026 • Version: 1.0 (Datathon Edition)
Important Hackathon Notice: These documents are provided for this hackathon/demo project (IBM Z Datathon 2026) and should be reviewed by a qualified legal professional before being used as production legal terms. Z-Sentinel AI is an educational demonstration prototype.

1. Commitment to Accessible Cyber Tooling

Z-Sentinel AI is dedicated to providing an inclusive and accessible interface for all security professionals and evaluators. We aim to conform to the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA standards.

2. Key Accessibility Measures

  • Semantic HTML5 Structure: Proper usage of landmark tags (<header>, <nav>, <main>, <aside>, <footer>) and hierarchical headings.
  • Color Contrast & Liquid Glass: The Liquid Glass design system is applied strictly to navigation framing. All analytical data cards use solid `#0C182B` high-contrast surfaces ensuring readability for users with low vision or color vision deficiencies.
  • Keyboard Navigation: All interactive buttons, simulator triggers, and modal dialogs are navigable using standard keyboard focus tab controls.
  • Text Resizing & Responsive Layouts: Full CSS variable scaling and fluid typography support viewport zooming without horizontal content clipping.
  • Alternative Text: Vector icons and logos are provided with meaningful text labels or aria-label descriptions.

3. Feedback & Remediation

If you encounter any accessibility barriers while evaluating Z-Sentinel AI, please let us know via the Contact Page so we can address them promptly.

1. Transaction Telemetry Pipeline

Data processed through Z-Sentinel AI traverses an audited pipeline designed to guarantee privacy protection before analytical processing:

Mainframe Event Stream (CICS / SMF Records)
  ↓
Integration Adapter (Payload Normalization)
  ↓
Privacy Guardian (Automated PII Detection & Redaction)
  ↓
Feature Engineering (Velocity, Geo-Entropy, Hour, Amount Deviation)
  ↓
ML Anomaly Detection (Scikit-Learn Isolation Forest Pipeline)
  ↓
Risk Scoring Engine (Composite Heuristic + ML Score: 0–100)
  ↓
SOC Telemetry Dispatch & Real-Time Alert Action

2. Data Minimization Principles

  • Boundary Sanitization: High-risk PII entities (such as 16-digit credit card PANs and 9-digit SSNs) are masked to the last 4 digits (e.g., ************3210) immediately upon arrival.
  • Zero Unsanitized Cloud Queries: The AI Security Copilot strictly redacts user inputs and sanitizes transaction memos before any optional external queries to Groq AI.
  • Transient Memory Buffering: Telemetry streams are processed in memory and aggregated into lightweight metric structures to minimize unnecessary disk persistence.

3. Data Classification Standards

All records handled within this demonstration adhere to standard enterprise confidentiality classifications:

  • Public: System documentation, architecture specifications, open-source code.
  • Internal Demo: Synthetic transaction logs (TX-DEMO-*), simulated threat indicators.
  • Confidential (Protected): Real user Google OAuth tokens (held in temporary browser memory only).

# Security Policy — Z-Sentinel AI

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Z-Sentinel AI and the integrity of mainframe cyber defense seriously. If you identify a potential security vulnerability within this repository or demonstration platform:

1. **Do NOT report security vulnerabilities via public GitHub issues or public discussions.**
2. Please email the project maintainers at `[SECURITY CONTACT EMAIL TO BE CONFIGURED]` with the subject line `[SECURITY DISCLOSURE] Z-Sentinel AI`.
3. Include the following details in your report:
   - Component or endpoint affected (e.g. `/api/analyze`, `auth-guard.js`, PII masking regex).
   - Detailed steps to reproduce the issue or proof-of-concept payload.
   - Potential impact on confidential data or system integrity.
4. **Never include real secrets, private API keys, or genuine personal identifiable information (PII) in your vulnerability report.**

## Responsible Disclosure & Remediation Timeline

* We will acknowledge receipt of your vulnerability report within 48 hours.
* We will investigate and provide an estimated timeline for remediation.
* We kindly request that you maintain confidentiality until an official fix is merged.
